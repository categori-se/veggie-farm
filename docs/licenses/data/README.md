The reusable collection combines separately attributed sources. The application's software license does not replace the terms of imported data.

[OpenFarm's data-license declaration](https://github.com/openfarmcc/OpenFarm/blob/d6b2e6622df92cd61ef2284b4f9575032f4442b2/README.md#data-license) covers its database. [The recovery project](https://github.com/thefullnacho/openfarm-crops-rescue/tree/754cfd75da007c17a628eca812632f326dc7cf10) supplies the 340-record snapshot and individual archive references. Neither source's software or media is imported here. Crediting a project does not imply endorsement.

Transformations retain stable source IDs, preserve unknowns, normalize recognized light labels, reject unusable dimensions and keep row spacing distinct from plant spacing. The original snapshot is preserved unchanged for reproducibility. Quality review is independent from redistribution rights; these community records remain horticulturally unverified.

# Gardening journey review — September 2026

This review follows the owner's requested learning → garden planning → seasonal tracking journey. “Available” describes implemented behavior, not survey accuracy or completion of the whole product.

| Journey | Available | Remaining work / next acceptance |
| --- | --- | --- |
| Learn about plants | Find Plants filters, scrolling table, comparison, plant reports; Studio library and seasonal comparison link to plant searches | Direct cultivar-preserving handoff into a chosen Studio bed. Find Plants’ Add to plan currently creates a notebook record, not a Studio placement. Avoid substituting a generic crop for a chosen cultivar silently. |
| Start a garden | No-account practice garden; four populated illustrative public examples; JSON backup | A guided start from goals and site conditions to a first bed. A complete browser-guided public-data capture and review wizard is not present. |
| Explore and plant | Explicit edit locks; parcel/bed/2D/3D workspaces; walking; bed-click transition and return; 3D library | Better species-specific silhouettes, better framing around tall mature plants, visible visitor location on the overhead map, and continued native 3D drag/drop acceptance. |
| Review through the seasons | Month/date sun controls, bounded shade comparisons; dated size scenarios | Leaf loss, crown gaps and terrain horizons remain unmodeled; geometric size scenarios are not biological predictions. |
| Track and compare | Seasons workspace: monthly bed snapshots, notes, two saved-plan diagrams, plant count changes, return to planning and backup | Unified observation timeline joining notebook records to exact Studio placements; real harvest and flowering comparisons across years. A snapshot records a design, not proof of planting or success. |
| Save and return | Browser-local plans, saved versions, JSON export | A clearer unified account/local save journey and conflict handling across the resource site and Studio. Keep the 48-version retention limit visible. |
| Public sample fidelity | Area-level research, traced/estimated geometry, proposed diverse planting | More verified species/accession records and independent image registration for each site. Proposed or historic garden features must not become asserted present-day inventory. |
| Media and self-hosting | Private media separate from public source; procedural plant fallback; deployment templates | More reviewed natural-setting photographs, approved model inventory and a guided self-deployment flow. Do not treat a reference catalog or a search result as asset reuse permission. |

Prioritize complete paths over additional panels. Next bounded feature: carry a chosen plant from Find Plants into Studio with identity intact, an explicit destination-bed choice, a clear fallback when no model exists, and return to the original plant information. Then join the resulting placement to dated observations without duplicating notebook records.

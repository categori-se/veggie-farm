# First garden plan

Studio’s “Start with a 4 × 8 bed” action opens a four-step guide:

1. Name a garden and review bed dimensions in feet. Cancelling creates nothing.
2. Choose one to six starter plant types and optionally enter a planned planting date. The guide places one of each, retaining their existing catalog dimensions. A conservative arrangement rejects choices that do not fit rather than overlapping them silently.
3. Review the real 2D/3D editor. “Move plants” explicitly enables planting edits. Reload resumes the guide with editing locked again. Other gardens and existing plantings are preserved.
4. Save a named version and download a full planner backup. Browser storage failure rolls back the update and retains the save form. Account uploads remain an explicit action in Account saves.

Progress belongs to the garden under `property.firstPlan`, with the setup bed ID and completed flag. Blank dates mean unknown or undecided; setup does not manufacture actual planting events. The guide uses existing workspace, placement, named-version and backup records, not a separate preview that must later be converted.

This is a starting arrangement, not a recommendation that the plants suit local light, climate, soil or season. First-visit landing simplification and persistent Simple/Advanced modes remain separate unfinished work. The initial starter palette is intentionally small; Find Plants and the planting library support further choices.

# Bed seasons

Open **Seasons** above the Studio canvas or in the Plants drawer. Choose a bed and month, optionally enter an observation or next step, and save its current design. Save another month or year to compare the plans. Earlier/later selectors stay scoped to that garden and bed. Comparing never restores or changes the current plan.

Each comparison shows saved planting positions and mature footprint symbols, a per-plant count comparison, and the recorded notes. Plant names lead back to Find Plants in a separate tab so the planning session stays open. The 3D plant library also offers a plant-information link. The diagrams are schematic, not photographs or evidence of actual growth. Historical plant names and dimensions are resolved using the currently loaded catalog.

**Continue planning this bed** opens its planting workspace with existing geometry locked. **Export garden backup** downloads the normal full planner JSON, including saved versions and their notes. Versions persist in the current browser/account storage context and use the existing 48-version retention limit. Export periodically for longer history. Loading a historical version remains a separate explicit action in Saved versions.

Notes are rendered as text, not HTML, and new notes are limited to 2,000 characters. Snapshot month uses a validated year/month value. Saving a snapshot does not manufacture phenology, harvest measurements or observed plant survival.

# Season reflections

My Garden offers three gardener-authored prompts for the selected year: what worked, what to change, and what to try next year. Entries are stored in `property.seasonReflections` by year with a gardener-reflection source marker and update timestamp. Each prompt allows 2,000 characters. Saving all empty prompts removes that year's entry. Other seasons, conditions, plantings and observations are unchanged.

Studio persists to its current local workspace with rollback on storage failure. Account garden home saves through the existing revision-checked account journal, changing only the selected garden. JSON backups and existing next-season planning retain the property records. The previous year's notes are available in a disclosure, and the next-year planning dialog presents the source season's saved reflection before planting choices.

Drafts survive year changes while the garden dialog remains open. Failed saves retain text; successful saves do not erase a newer draft created while a save was pending. Closing the dialog discards unsaved drafts. Notes express the gardener's interpretation and are not generated conclusions or changes to the planting plan.

Verification covers immutable updates, seasonal isolation, selected-account-garden isolation, failed saves, draft year switching, JSON reload and next-year display at desktop/phone widths. Real authenticated cross-device acceptance remains outstanding.

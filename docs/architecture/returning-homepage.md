# Returning garden on the resource homepage

The homepage mounts a compact version of the same selected-account-garden component used by Today and Notebook. A remembered owner-scoped save/garden selection places its garden summary, dated record prompts and contextual logging above the general resource introduction. Choose or change garden contains the less frequent selection/linking controls.

Fresh visitors without a remembered account selection keep the resource homepage, with no automatic account-garden request. A remembered selection loads only that account save once. A failed restore stays visible for recovery; an owner change clears the previous garden. Plant discovery, seasonal guidance, knowledge links and source explanations remain on the homepage.

This reuses existing account services and browser-scoped selection. No new AWS service, scheduled job or private-data cache is added. Garden contents are not embedded in the static homepage. Unsaved Studio-only gardens are not discovered across the domain boundary.

Browser acceptance with a synthetic account client covers fresh/returning desktop and phone visits, zero requests without selection, one request with selection, hidden management controls, exact planting logging, owner change and retained resource navigation. Real authenticated cross-device acceptance remains outstanding.

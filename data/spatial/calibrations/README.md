# Garden alignment manifests

These JSON files preserve the ground-control observations and assumptions used to align editable starter layouts. They conform to `src/data/gis-alignment.schema.json` and are checked by `npm run spatial:align:check`.

See `docs/gis-alignment-workflow.md` before adding or revising a manifest. Do not store downloaded statewide archives, address-search requests, private assessor attributes, or unlicensed imagery here.
